# StyleMatch
A Python fashion style quiz developed for my UTS Creative Coding project.
About the Project

StyleMatch is an interactive fashion style quiz developed using Python and Flet for my UTS Creative Coding project.

The application asks users six multiple-choice questions to identify their personal fashion style.

At the end of the quiz, users receive a style result and outfit recommendations.

Features

Six interactive multiple-choice questions

Four fashion styles: Minimalist, Trendy, Classic and Sporty

Personalised outfit recommendations

Pink-themed user interface

Progress bar to track quiz completion

Option to restart the quiz

Technologies Used

Python 3

Flet

Visual Studio Code

How to Run

Install Python 3.

Install Flet using python3 -m pip install flet.

Download the project files.

Open the project folder in VS Code.

Run python3 stylematch_app.py in the terminal.

Project Purpose

This project was created to develop my understanding of Python programming, conditional logic, data structures, functions and interactive application design.
